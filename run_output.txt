── WHAT'S HAPPENING DURING RUNTIME ───────────────────────────────────────────

While the system runs, the following happens on every frame (~30 FPS):

  MAIN THREAD (Frame Loop):
    1. Reads a frame from the camera (640x480 BGR)
    2. Sends the frame to Detection Thread (async, non-blocking)
    3. Sends the frame to Lane Thread (every 2nd frame)
    4. Sends the frame to Pothole Thread (every 3rd frame)
    5. Collects latest results from all threads
    6. Runs the Driving State Machine to decide:
       - Current state: DRIVING / BRAKING / AVOIDING LEFT / AVOIDING RIGHT /
         REVERSING / POTHOLE DODGE / STOPPED (RED LIGHT) / STOPPED (STOP SIGN)
       - Throttle value: 0-60 (forward), -25 (reverse)
       - Steering angle: 0-180 degrees (90 = straight)
    7. Draws visualization on the frame:
       - Green lane lines (temporally smoothed, averaged)
       - Bounding boxes with Indian class names (Car/Auto, Bike/Scooter,
         Lorry/Truck, Cow/Bull, Dog, Sheep/Goat, Person, etc.)
       - Distance estimates for vehicles and animals
       - Pothole ellipses with severity labels (MINOR/MODERATE/SEVERE)
       - Collision ROI trapezoid (Green/Yellow/Red based on hazard)
       - HUD: FPS, object count, pothole count, driving state, steering/throttle
       - Warning alerts for critical obstacles
    8. Displays the frame fullscreen

  DETECTION THREAD:
    - Runs YOLO11n inference at 640px on every frame it receives
    - Detects 14 Indian road classes (Person, Bicycle, Car/Auto, Bike/Scooter,
      Bus, Lorry/Truck, Traffic Light, Stop Sign, Cat, Dog, Horse, Sheep/Goat,
      Cow/Bull, Elephant)
    - Confidence threshold: 0.35 (high recall for dense Indian traffic)
    - Agnostic NMS enabled (prevents bus being detected as car too)
    - Runs collision warning checks on all detections
    - Estimates distances using pinhole camera model

  LANE THREAD:
    - Dual-channel edge detection (Grayscale + HLS Saturation)
    - Adaptive Canny thresholds based on lighting conditions
    - Hough Line Transform with length-weighted least-squares fitting
    - Outputs exactly 0-2 clean averaged lane lines
    - Temporal EMA smoothing for stable, jitter-free lanes

  POTHOLE THREAD:
    - Analyzes road surface in bottom 40% of frame
    - Adaptive thresholding to find dark patches
    - Contour filtering by area, aspect ratio, and circularity
    - Classifies severity: MINOR / MODERATE / SEVERE
